# Update a GitHub installation without resetting it

Do not remove or uninstall the existing extension. Chrome deletes its local extension data when it is removed.

1. Extract the new release over the same permanent folder used by the installed GitHub version.
2. Replace the existing files when prompted.
3. Open chrome://extensions.
4. Click Reload on Nexus Ore Radar.

Do not load the update from a new version-named folder. Keeping the same folder keeps the unpacked extension identity and preserves its saved setup and local data.
