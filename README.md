# Nexus Ore Radar

Chrome extension for Nexus Legacy with mining-belt search, saved origins, mining analytics, fleet presets, destination optimization, mission context and report capture.

## Install from GitHub

1. Download [`Nexus-Ore-Radar-0.3.2-release.zip`](downloads/Nexus-Ore-Radar-0.3.2-release.zip?raw=1).
2. Extract the ZIP to a permanent folder.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
6. Keep Nexus Legacy open and signed in, then open Nexus Ore Radar from the Chrome toolbar.

## Update a GitHub installation without resetting it

**Do not remove or uninstall the existing extension.** Chrome deletes its local extension data when it is removed.

1. Download the newest release.
2. Extract it over the same permanent folder used by the installed GitHub version and replace the existing files.
3. Open `chrome://extensions`.
4. Click **Reload** for Nexus Ore Radar.

Do not load the update from a new version-named folder. Keeping the same folder keeps the unpacked extension identity and preserves its saved setup and local data. See [UPDATE-GITHUB.md](UPDATE-GITHUB.md) for the same update instructions included with release packages.

## Data contribution

Using Nexus Ore Radar requires accepting the in-extension data notice. Eligible complete Season 0 mining pirate-raid reports are contributed to the maintainer for further development. Other seasons and ordinary mining-yield or breakdown reports remain local. Existing reports are not ingested when the extension is first used; capture starts with reports that arrive afterwards.

See [PRIVACY_POLICY.md](PRIVACY_POLICY.md) for the complete data-use, retention and removal information.
